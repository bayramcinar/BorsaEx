📊 CanlıDöviz – Borsa Takip Chrome Eklentisi

CanlıDöviz verilerini kullanarak arama tabanlı borsa takibi, favori enstrüman yönetimi ve anlık fiyat bilgisi sunan bir Chrome Extension.
Bu eklenti, tüm hisseleri toplu çekmek yerine kullanıcının aradığı enstrümanları getirir ve yalnızca favorilere eklenenleri düzenli olarak günceller.

✨ Özellikler

🔎 Anlık Arama

https://canlidoviz.com/api/search?q=... kullanır

Hisse, sertifika, endeks, özel enstrüman desteği

⭐ Favori Yönetimi

İstenilen enstrüman favoriye eklenebilir
Favoriler chrome.storage.local içinde saklanır

📈 Detaylı Enstrüman Bilgisi

-> Fiyat
-> % Değişim
-> Değişim Tutarı
-> Günlük Yüksek / Düşük
-> Dünkü Kapanış
-> Son Güncelleme Zamanı

📉 Grafik Görüntüleme

TradingView destekliyse → TradingView grafiği
Desteklenmiyorsa → CanlıDöviz sayfasına yönlendirme

⚡ Hafif & Performanslı

Tüm BIST verisi çekilmez
Sadece aranan ve favori eklenen veriler işlenir
